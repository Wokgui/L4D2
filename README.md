# Archives L4D2

Catalogue personnel de campagnes *Left 4 Dead 2* avec quatre catégories : **Oui**, **Pourquoi pas**, **Bof** et **Non**.

## Fonctions

- fiches détaillées pour les campagnes conservées ;
- recherche globale et tri ;
- remarques issues du catalogue historique ;
- tirage aléatoire filtré par difficulté et longueur ;
- ajout manuel de campagnes ;
- modification locale des fiches ;
- sauvegarde et restauration par export/import JSON ;
- installation PWA et fonctionnement hors ligne.

Le projet est une application statique : aucun service côté serveur ni variable d’environnement n’est requis.
