ARCHIVES L4D2

Utilisation immédiate : ouvrir index.html dans un navigateur récent.
Déploiement : envoyer tout le contenu de ce dossier sur un hébergement statique (Vercel, Netlify, GitHub Pages, etc.).

Les modifications de fiches et les campagnes ajoutées manuellement sont conservées dans le navigateur. Utilisez « Exporter » pour créer une sauvegarde, puis « Importer » pour la restaurer sur un autre appareil.

Fichiers d’audit :
- RAPPORT-FUSION.md : résumé de la comparaison.
- comparaison.csv : correspondance détaillée JSON / Excel.
- campagnes-fusionnees.json : base complète fusionnée.
